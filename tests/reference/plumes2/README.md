# PLUMES2.0 golden references

This directory will hold project-owned regression captures generated by the immutable archived executable in `PLUMES2.0-main/`.

Do not place edited copies back into the archive.

For each case preserve:

- exact input files;
- raw PLUMES output;
- a manifest with executable SHA-256/version and runner details;
- normalized comparison data generated by repository tooling.

The first capture is tracked by `PLUMES-REF-1` in [docs/GATES.md](../../../docs/GATES.md).
