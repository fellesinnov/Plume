## Candidate implementation

MODEL-1 adapts Ebb Carbon's MIT-licensed single-port Lagrangian-control-volume architecture pinned by REF-1. `THIRD_PARTY_NOTICES.md` records the attribution and license. SFEI Visual Plumes remains an external GPL oracle; no GPL implementation code is incorporated.

The candidate adds:

- a 9-state continuous Lagrangian control volume conserving element mass, 3-D momentum, mass × Conservative Temperature, mass × Absolute Salinity, and ENU position;
- source contraction and element stretching/radius relations adapted from the pinned Ebb implementation;
- navigation azimuth mapped explicitly to ENU (`+x east`, `+y north`, `+z up`), with positive-down depth reported separately;
- a separate MODEL-1 physics outlet registry so structural config support never silently implies a qualified physics adapter;
- explicit ambient full-water-column coverage and linear depth interpolation of Absolute Salinity, Conservative Temperature and horizontal current components;
- a pressure-aware thermodynamic interface with a production `GswThermodynamics` adapter for TEOS-10 / GSW; no EOS-80/Knudsen fallback is permitted in product code;
- adaptive LSODA integration with dense output and explicit surface-edge, seabed-edge, dilution, non-physical, trapping and vertical-reversal events;
- decoded `UM3_REFERENCE` entrainment and the published projected-area candidate behind one internal closure interface while `MODEL-CLOSURE-1` remains open;
- a vertical-trajectory cross-current limit so an initially vertical jet begins bending/curving rather than forcing its first elevation derivative to zero.

`UM3_REFERENCE` is the qualification/software-regression default only. It is not frozen as the customer-facing physical production closure.

## Physical qualification debt

MODEL-1 does **not** retire its physical qualification gate in this candidate.

REF-1 deliberately reserved:

- Fan (1967) as formulation/calibration evidence; and
- Lee & Cheung (1991) heated, buoyancy-dominated weak-current data as untouched hold-back.

The public-source pass confirmed the papers/case families but still did not obtain a clean, machine-readable original numerical observation table with sufficiently clear provenance for the selected Fan and Lee-Cheung cases. No values were digitized from plots to manufacture goldens.

Therefore:

- `MODEL-CLOSURE-1` remains **OPEN**;
- `MODEL-TOL-1` remains **BLOCKED**;
- no production closure or physical acceptance tolerance is frozen;
- reference agreement must not be called permitting proof.
