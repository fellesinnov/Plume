## Source decisions

1. Two new providers registered under the existing normalized provider registry: `csv_time_depth_profile` and `csv_time_vector_profile`. No proprietary provider code or HeatHandler UI dependency.
2. `HistoricalForcing` is SHA-bound to request (site, forcing clock, ambient/plant original provider specs, resolved CSV filenames and raw-file digests) and normalized result (timestamp index, provenance, explicit gaps). Geometry is deliberately excluded from provider request identity. Cache lives in ignored shared/private workspace; source CSV changes force new SHA/new cache; corrupted cache fails loudly. `refresh=True` is explicit.
3. Sampling is exact second UTC on `[start,end)`; every selected column must cover 0 m to full water depth, no implicit gaps/temporal interpolation. Historical source descriptors stay time-dependent and a DESIGN-1 locked constant candidate is rejected.
4. Full-depth ENU profile preserved in optional `PinnedSnapshot.current_profile_east_north_mps`. Only present when needed; original old snapshot hash/payload stays unchanged for constant currents. MODEL-1 ambient levels interpolate u/v at depth through existing provider-neutral evaluation.
5. Pre-index timestamped records and verify data identity once for `iter_available` rather than O(year×year) scans. The model is not run in TIME-1A; actual annual near-field/field/criteria loop belongs to later sprint.
