## Technical decisions / adversarial review

- Copernicus adapter uses the documented `copernicusmarine.open_dataset` API on a bounded WGS84/time/depth subset, requesting only normalized provider-role variables. No auth fields in config or logging; credentials remain external. `dataset_id` is explicit and no unverified identifier is presented as guaranteed working.
- Temperature role is **explicit** in config: in-situ ITS-90 or potential temperature referenced to zero pressure (`thetao`, pt0); the latter is never mislabelled. Salinity must explicitly be declared Practical Salinity; current is u/v east/north m/s. Missing units/native convention, mismatched roles, NaN/masked columns or missing depth bracket fail or create declared gaps. A candidate coastal cell is assessed only through the first native level bracketing requested seabed, never rejected for masked *deeper unused* levels. Native potential-temperature metadata cannot be overridden by an in-situ knob; role-incompatible descriptor options fail rather than being dropped.
- Some Copernicus variables ship as separate datasets; thetao without co-dataset so remains an explicitly potential-temperature history and is paired to **same-hour** SP from its own provider when a design snapshot is pinned, then converted via GSW. A co-located so companion in the same dataset can instead be converted within the provider. The selected-cell coordinates and transformation method are retained.
- Wet-cell fallback bounded by explicit distance, top-cell hold to 0 m flagged as proxy, bottom strictly bracketed; >2 km cross-variable wet-cell mismatch fails. No invented fjord data. The cache is SHA-pinned by requested site, clock, normalized provider descriptors and local raw CSV hashes; explicit refresh for live dataset updates.
- Streamlit new-project map provides optional click-to-propose WGS84 coordinates with numeric override. Ocean explicitly loads history, shows gap-preserving T/SP/u/v section-time plots and selects one hour, and pins using the same core DESIGN-1 snapshot. The original Plot/Design/criteria code stays headless.
- Locked DESIGN-1 config carries one design operating flow/temp; replay restores original full plant provider descriptors from its pinned snapshot before comparing with the acquired history and solving. A source-config mismatch preflight fails; no replacement with the design constant. A bounded runner saves actual per-hour near-field MODEL-1/FIELD-1 metrics, `MISSING` rows and output integrity SHA-256. Completed manifests identify config/revision/model/provider SHA, and failed archives never appear completed.
- P95/P99 are explicitly **sampled-slice model indicators**, not permit pass/fail statistics; no exceeding hours/legal criteria or far-field and no false completion of physical gates.
