# Documentation map

- [METHOD.md](METHOD.md) — how work is split, tested and evidenced.
- [buildlog/README.md](buildlog/README.md) — current status/evidence owner.
- [USER_INPUT.md](USER_INPUT.md) — durable accepted direction from the human.
- [BACKLOG.md](BACKLOG.md) — live work queue with retirement evidence.
- [GATES.md](GATES.md) — unresolved manual/reference evidence.
- [MODEL_REFERENCE.md](MODEL_REFERENCE.md) — immutable PLUMES2.0 archive and golden-reference contract.
- [settings/chatgpt.md](settings/chatgpt.md) — seed for the dedicated ChatGPT Project instructions.

The existing root [MODEL_NOTES.md](../MODEL_NOTES.md) and [SCREENING_PROCEDURE.md](../SCREENING_PROCEDURE.md) remain beside the prototype for now.
